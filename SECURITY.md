# Security reports

Send suspected vulnerabilities to contact@modeluplink.com with enough detail to
reproduce the issue. Do not post tokens, sign-in codes, endpoint keys, account
profiles, or exploitable vulnerability details in public issues. Do not include
other people's data in a report.

The public code covers the software that runs on the user's machine. The hosted
service is a separate trust boundary. Source availability alone does not verify
the hosted deployment or prove that a binary matches this source. Release
attestations provide build provenance; see RELEASING.md for verification.
